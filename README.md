## What it does

`main.py` writes exactly one character to `/output/entry.txt` — the
single letter **A**, standing for coffee: the fuel of a nonstop building
day. Nothing else is in the file: no word, no explanation, no
punctuation, no trailing newline.

## Run it

```sh
python3 main.py
```

## Files

- `main.py` — the entrypoint: writes the single letter (Python standard
